# Expected demo behavior — not a factual clinical report

The demo should produce a report with:

- a concise problem statement for avoidable ED utilization;
- evidence retrieved from arXiv/SEC plus CMS/CDC context;
- explicit distinction between evidence and inference;
- navigation opportunities such as primary care, urgent care, telehealth or care-management follow-up when supported;
- a safety guardrail stating that genuine emergencies should not be delayed or blocked;
- a References section tied to the evidence records;
- limitations explaining that synthetic data are for demonstration/testing and not for beneficiary inference.
